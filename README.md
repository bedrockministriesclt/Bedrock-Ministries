# Bedrock Ministries Website

Static website built for GitHub Pages.

## Pages
- `index.html` — Home
- `about.html` — About
- `stories.html` — Stories
- `find-housing.html` — Prospective resident pathway
- `create-margin.html` — Donor/supporter pathway

## Before launch
1. Replace the temporary email CTA on `find-housing.html` with the final Bedrock inquiry form URL.
2. Confirm all board titles and current organization affiliations.
3. Confirm any new impact statistics before adding them.
4. Test all external links.
5. Add the custom domain in GitHub Pages only after the site is approved.

## GitHub Pages
Upload the contents of this folder to the repository root. Then go to:
Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
